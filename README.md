# Claim Preregistration — Methods Kit

**Explore online:** [Open the public interactive website](https://luckygithub777.github.io/claim-preregistration-methods/). The hosted experience is the primary visitor entry point; source files and optional local use remain available here.

An educational toolkit with an interactive browser companion for writing a question, freezing a test plan, identifying controls and stopping rules, and keeping outcome claims within measured evidence.

Start with the [preregistration template](templates/preregistration.md), then the [claim-test card](templates/claim_test_card.md). A [synthetic target pool](examples/target_pool.json) illustrates sample materials. The [claims policy](docs/CLAIMS_POLICY.md) explains limitations and evidence labels.

**No anomalous-information mechanism or human performance is verified by this kit.** It contains no human-subject records or live hidden targets. Real participant studies require independent consent, ethics, privacy, and governance arrangements.
